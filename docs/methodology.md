# Assessment workflow

1. Confirm written authorization, owners, dates, and emergency contacts.
2. Record explicit in-scope assets and exclusions.
3. Collect only approved inventory and operator-supplied metadata.
4. Map applications and endpoints from approved documentation or local exports.
5. Record observations with reproducible evidence and impact.
6. Review findings with the system owner.
7. Export the report and securely archive or dispose of engagement data.

This tool is a record-management aid, not proof of authorization and not a substitute
for a formal Rules of Engagement document.
